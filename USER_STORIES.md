# Phytoseal — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Forwarder document clerk

- As a document clerk, I want to register an ePhyto and see import-side acceptance, so that I stop couriering originals.
- As a document clerk, I want governed amendments, so that inevitable corrections do not break trust in the ledger.

### Customs broker

- As a broker, I want ai-proposed HS codes with rationale, so that 200 new materials a day do not stall filings.
- As a broker, I want to override AI with annotated reasons, so that expert judgment remains authoritative.
- As a broker, I want outdated code alerts, so that ECCN/HTS drift is visible.

### Port platform operator

- As a platform operator, I want parties onboarded to one backbone connection, so that integration cost stays linear.
- As a platform operator, I want disclosure policies per document class, so that competitors do not see each other’s commercial data.

### Trusted-trader / AEO lead

- As an AEO lead, I want evidence of certificate authenticity and classification reviews, so that C2B trust programs have artefacts.
- As an AEO lead, I want exception reports when auto-flows are legally suspended, so that risk is explicit.

### NPPO liaison

- As an NPPO liaison, I want presentation status for plant-product shipments, so that border agencies see the same sealed record.
- As an NPPO liaison, I want to reject a certificate with reason codes, so that invalid docs do not silently clear.
